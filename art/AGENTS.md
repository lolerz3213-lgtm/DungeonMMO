# Environment art workflow

This branch is art-only; no gameplay source, merges, commits, pushes or publishing.
Read `references/DUNGEON_STYLE_GUIDE.md` in normal mode; do not visually reanalyse
unchanged references. "Rescan for new dungeon references" invokes the incremental
workflow documented there and `scripts/references/scan_references.py --rescan`.
Read `library/ASSET_CATALOG.md` before creating any asset. Reuse first, then variant,
then genuinely new modelling; register useful assets, sources, exports and thumbnails.
Keep visual evidence and outstanding limitations in art documentation.
